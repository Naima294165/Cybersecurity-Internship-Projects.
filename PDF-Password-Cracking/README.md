# PDF Password Cracking

## Overview
This project documents my Week 3 cybersecurity internship practical, focusing on PDF password cracking using instructor-provided practice files and cybersecurity tools.

## Objectives
- Understand PDF hash extraction.
- Explore PDF hash formats.
- Gain practical experience with password-cracking tools.
- Document and verify practical results.

## Tools Used
- John the Ripper (Jumbo)
- Johnny GUI
- Online PDF Hash Extractor
- Networkwalks-provided password-cracking tool

## Practical Activities
Four instructor-provided PDF files were used during the exercise.

| Practice Files | Tool Used |
|---|---|
| PDF 1 and PDF 2 | John the Ripper / Johnny |
| PDF 3 and PDF 4 | Networkwalks-provided tool |

The practical involved extracting PDF hashes, examining hash formats, using the assigned tools and verifying the results.

## Key Learning Outcomes
- Understood how PDF hashes are extracted.
- Gained familiarity with PDF hash formats.
- Explored different password-cracking tools.
- Learned to document practical results and verify outcomes.

## Evidence
Screenshots documenting the practical activities and successful PDF verification are organised in the Evidence folders.

## Scope
All activities were conducted using instructor-provided practice files as part of an authorised cybersecurity training programme.

## Conclusion
This practical strengthened my understanding of PDF password cracking and provided hands-on exposure to different cybersecurity tools.
