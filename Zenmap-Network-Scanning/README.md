# Network Scanning Using Nmap and Zenmap

## Overview
A practical exercise using Nmap through Zenmap to identify responsive hosts on a local network.

## Objective
To identify active hosts and understand basic network discovery.

## Tools Used
- Kali Linux
- Nmap
- Zenmap
- Oracle VirtualBox

## Scan Configuration
- Scan type: Ping Scan
- Network: `192.168.100.0/24`
- Addresses scanned: 256

## Results
Four responsive hosts were identified during the scan.

The network topology output was saved as a PDF.

## Key Learning Outcomes
- Identifying a local network and subnet.
- Performing a Ping Scan using Zenmap.
- Identifying responsive hosts.
- Viewing network topology results.
- Recording and documenting scan findings.

## Conclusion
This exercise provided practical experience with basic network discovery using Nmap and Zenmap. Host discovery identifies responsive devices but does not establish that those devices are vulnerable.
