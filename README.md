# Kali Linux VirtualBox Setup

## Project Overview
This project involved setting up a virtual cybersecurity lab using Oracle VirtualBox and Kali Linux.

## Tasks Completed
- Installed 7-Zip and Oracle VirtualBox.
- Configured a NAT Network.
- Downloaded and configured the Kali Linux virtual machine.
- Set up a static IP address (`10.0.0.2/24`).
- Troubleshot internet connectivity.
- Created a VirtualBox snapshot.

## Skills Learned
- Virtual machine setup and configuration.
- NAT networking and IP configuration.
- Basic network troubleshooting.
- Virtual machine snapshots.
- Technical documentation.
